Brasil Dev Kit. CEP, IBGE, feriados e CNPJ com tipos e erros previsíveis.

Um SDK TypeScript e uma API HTTP pública para os dados brasileiros que todo sistema acaba precisando. Cada resposta diz de onde veio o dado, todo erro tem um código estável e nada depende de chave paga.

/sdk

No seu código

TypeScript strict, ESM e CommonJS, zero dependência em runtime. Node 22 ou mais novo.

  1. 1

    Clone e gere o build

    O pacote ainda não está publicado no npm. Até lá, use a partir do código.

    git clone https://github.com/Efer-Eder/brasil-dev-kit.git
cd brasil-dev-kit
pnpm install
pnpm build
  2. 2

    Consulte e trate os erros pelo tipo

    Cada falha vira uma classe com code estável: ValidationError, NotFoundError, RateLimitError, TimeoutError, ProviderUnavailableError.

    import { createCepClient, NotFoundError } from 'brasil-dev-kit';

const cep = createCepClient({ timeoutMs: 8000 });

try {
  const endereco = await cep.lookup('01310-100');
  console.log(endereco.municipio, endereco.fonte.provedor);
} catch (error) {
  if (error instanceof NotFoundError) console.log('CEP não existe');
  else throw error;
}
  3. 3

    Funções que não precisam de rede

    Feriados e CNPJ rodam localmente, sem requisição nenhuma.

    import { isFeriadoNacional, getFeriadosNacionais, validateCnpj } from 'brasil-dev-kit';

isFeriadoNacional('2026-11-20');    // true
getFeriadosNacionais(2026).origem;  // 'portaria'
validateCnpj('12.ABC.345/01DE-35'); // { valid: true, kind: 'alphanumeric', ... }
/fontes

De onde vem cada dado

A API é minha. Os dados vêm de fontes públicas, e cada resposta diz qual.

01

CEP

ViaCEP primeiro. Se ele estiver fora do ar, lento ou limitando, a consulta cai para a BrasilAPI. O campo fonte diz quem respondeu.

viacep.com.br · BrasilAPI

02

UFs e municípios

API de Localidades do IBGE, a fonte oficial. Códigos sempre como texto, para bater com o código do município no CEP.

servicodados.ibge.gov.br

03

Feriados

Leis federais para os feriados e a portaria anual do governo federal para os pontos facultativos. Ano sem portaria publicada vem só com o que está em lei, e avisa.

Leis 662/1949, 6.802/1980, 14.759/2023 · Portarias MGI

04

CNPJ

Cálculo local dos dígitos verificadores, inclusive do CNPJ alfanumérico, conforme o manual oficial. Valida formato, não consulta cadastro.

IN RFB nº 2.229/2024 · manual de DV do Serpro

/limites

Limites e números

Gratuita e sem SLA. Para uso pesado, rode o SDK no seu servidor.

10 req/spor IP, com rajada de 30. Acima disso: 429 com Retry-After.
7 diasde cache para cada CEP encontrado. CEP inexistente fica 6 horas; UFs e municípios, 24 horas.
~880 req/smedidos no servidor com cache quente, usando meia CPU. Mediana de 6 ms.
4 sde timeout por provedor. Com fallback, uma consulta de CEP leva no máximo cerca de 8 s.
4 req/sno máximo para cada provedor externo, para não sobrecarregar serviços gratuitos.
0IPs ou consultas guardados em log da aplicação. Só contadores agregados.

/perguntas

Perguntas frequentes

Clica numa pergunta que o Ponto responde.

Posso usar a API em produção?

Pode, sabendo que é gratuita e sem garantia de disponibilidade. Para tráfego alto ou algo crítico, rode o SDK no seu próprio servidor: o código é o mesmo.

Por que a primeira consulta de um CEP demora mais?

Porque ela vai até o provedor público. A partir daí o CEP fica em cache por 7 dias e responde em poucos milissegundos. O cabeçalho X-Cache mostra se foi HIT ou MISS.

A validação de CNPJ diz se a empresa existe?

Não. Ela confere formato e dígitos verificadores, inclusive do CNPJ alfanumérico. Existência e situação cadastral só a Receita Federal informa.

Os feriados incluem os estaduais e municipais?

Ainda não. Hoje são os feriados nacionais e os pontos facultativos do governo federal, cada um com a lei ou portaria de origem.

Vocês guardam o que eu consulto?

A aplicação não registra IP nem o que foi consultado, só contadores agregados. O cache guarda o dado público do CEP, não quem pediu.

Como contribuo?

Abre uma issue ou um pull request no GitHub. O CONTRIBUTING explica o padrão: testes junto com o código e nenhuma integração sem documentação oficial citada.
