# Código de Conduta

Este projeto adota os princípios do [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Resumo do compromisso

Queremos que participar deste projeto seja uma experiência acolhedora e livre de
assédio para todas as pessoas, independentemente de idade, corpo, deficiência,
etnia, identidade ou expressão de gênero, nível de experiência, escolaridade,
nacionalidade, aparência, raça, religião ou orientação sexual.

**Esperado:** empatia, respeito a opiniões diferentes, críticas construtivas,
assumir responsabilidade por erros e foco no que é melhor para a comunidade.

**Inaceitável:** linguagem ou imagens sexualizadas, insultos, ataques pessoais
ou políticos, assédio público ou privado, publicação de informações pessoais de
terceiros sem permissão e qualquer conduta inadequada em ambiente profissional.

## Aplicação

Casos de comportamento inaceitável podem ser relatados de forma privada ao
mantenedor pelo perfil do GitHub [@Efer-Eder](https://github.com/Efer-Eder).
Todas as denúncias serão analisadas com confidencialidade. O mantenedor pode
remover comentários, commits ou contribuições e bloquear participantes que
violem este código, conforme as diretrizes do Contributor Covenant.
